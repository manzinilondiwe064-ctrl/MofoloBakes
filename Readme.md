# Bella's Bakes - Luxury Cakes by Bella, Soweto
Part 3 - Final Website Submission

Student: Londiwe Manzini
Module: WEDE

 Project Description
Bella's Bakes is a luxury custom cake studio in Mofolo, Soweto. The website allows customers to view cakes, check working hours, find us on map, and place orders via enquiry form.

Website Pages (5 Pages)
1. index.html - Home page with luxury banner and best sellers
2. about.html - About Bella, Inside Our Kitchen, Working Hours
3. creations.html - Our Luxury Cake Collection (6 cakes with images, prices, Order Now)
4. enquiry.html - Place Your Order form
5. contact.html - Contact & Order + Where Are We Mofolo

 Features Added in Part 3
- Responsive design (works on phone and PC)
- Search cakes function
- Order Now buttons linked to enquiry form
- Google Maps embed - Find Us in Mofolo
- FAQ section (How long to order? Delivery?)
- Working Hours: Mon-Fri 08:00-18:00, Sat 08:00-16:00, Sun Closed
- Delivery: Mofolo FREE, Soweto R100, Sandton R150, FREE from R1500
- Enquiry form with validation (Contact Person, Address, City, Region, Postal, Cake Choice, Quantity, Event Date, Phone, Email, Message)
- WhatsApp integration - sends order to 081 234 5678

 Technologies Used
- HTML5
- CSS3 (styles.css)
- JavaScript (form + search + WhatsApp)
- Google Maps API
- Leaflet Map

## How to Run the Website
1. Open folder in VS Code
2. Click Go Live (bottom right)
3. Website opens at http://127.0.0.1:5500/index.html
4. Navigate using top menu
